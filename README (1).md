# CodeAlpha - Basic Chatbot

## Task 3: Basic Chatbot

### Description

This project is a simple rule-based chatbot developed using Python as part of the **CodeAlpha Python Programming Internship**.

The chatbot interacts with users through the console and provides predefined responses to common inputs such as greetings, questions, and farewell messages. The conversation continues until the user enters **"bye"**, **"exit"**, or **"quit"**.

---

## Features

* Console-based chatbot
* Responds to greetings
* Answers simple predefined questions
* Provides help information
* Handles unknown inputs gracefully
* Allows the user to exit the conversation using **bye**, **exit**, or **quit**
* Uses random responses to make conversations more interactive

1. Download or clone this repository.

